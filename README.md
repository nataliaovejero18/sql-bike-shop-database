# SQL Bike Shop Database

## Project Overview
This project consists of designing and implementing a relational database for a bike shop using SQL.

## Objectives
- Create database structure
- Define relationships between tables
- Perform queries for data analysis

## Methodology
- Database design (ER model)
- Table creation
- Data insertion
- Query execution

## Tools
- SQL

## Key Features
- Structured database design
- Use of queries to retrieve meaningful information

## What I learned
This project helped me understand how databases work and how SQL can be used to manage and analyze structured data.
